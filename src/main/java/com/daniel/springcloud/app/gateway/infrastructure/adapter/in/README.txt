Aquí solo se tienen las carpetas de api, mobile y web
En api, componentes que ayuden a recibir las peticiones desde clientes api
En mobile, componentes que ayuden a recibir las peticiones desde clientes mobile
En web, componentes que ayuden a recibir las peticiones desde clientes web

Por cada una están las carpetas controller, dto y mapper

En controller, controladores que reciben las peticiones desde afuera del sistema
En dto, clase que estructura la información como la envie el cliente en cuestión
En mapper, clases que traducen de dto a modelo y de modelo a dto
